# LegacyOS

LegacyOS is the operating platform solution for organizing a complex gym that provides multiple products and spaces, and requires coaching.

It manages:

- Families
- Athletes
- Memberships
- Scheduling
- Reservations
- Attendance
- Billing
- Door Access
- Coaching
- Reporting
